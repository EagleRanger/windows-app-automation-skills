# 阶段二：模板填充与运行

目标：复用已过小样的方法，让内容、页序和版式随批量增加而保持一致。

## 操作模式

1. 核对模板与来源指纹，消费阶段一的交接；方法/输入改变则只重测受影响部分。批量前运行项目现有准入检查，必要时使用随附回执检查器。
2. 用稳定材料ID绑定正式标题、目录简称、原件页和输出对象。正式标题按title-transcription.md直接填入已核实的source_title，排版阶段无文字改写权限；严禁用简称、旧转换文字或重新生成字符串替代。成品物理页码仅作生成后的定位结果，不能作为下一轮源页锚点。原件清单独立于目录，禁止两个来源各自猜顺序。
3. 原件优先从PDF实际可见页渲染，保留比例、方向和全部可见内容；嵌入图片提取须先证明与该可见页一致。清除转换产生的OCR重复文字前，先证明同一内容已由保留原件承载。
4. 在模板规定的可用空间内等比放置，分别安排外加标题、图像及新页码。遇到放不下，先查重复边距、错误来源/裁切、标题行距和分页设置；不默认缩小全文、拉伸图片或白条遮盖。
5. 标题/目录/可编辑正文用原生对象，扫描及获授权的电子附件可图片化。PDF对象附件可作为额外原件保存，但不能以需要双击才能看到的嵌入对象代替用户要求的可见打印页面。
6. 版式与分节稳定后，导出读取实际物理页、正文印刷页及标题定位，回填目录并复导出至稳定。自动目录域与可编辑静态目录分别声明；不能用截图目录满足编辑需求。
7. 每个批次保留范围、来源映射、模板版本和问题位置。新页型或共有碰撞触发小样检查；冻结已过项，不不断重生成全册。

## 运行中的排版检查

- 每批检查最长标题、首末页和衔接页：字号/粗细/行距未漂移，标题不独占空页，不压图、不留末字在图下，不为凑页数删材料。
- 全局目录修改后检查所有目录页及正文起点；页脚修改也可能改变分页。封面/目录不编号只在本次要求如此时执行，不推广为所有报告规则。
- 满页表格检查最后一行、下边框和签章；零散印章、条码、水印不能因尺寸小就作为杂项删除。原件自带页码可随原件保留，新册页码单独核对。
- 图像“布满”以范本的可见内容尺度和版心为准，不是强行拉满纸边。保留原件空白与裁去空白的权限不同；需要裁切或分割时核对授权和完整性。
- 长截图按用户已授权方式分连续页；记录每段源行区间，段间无漏行/重复，断点不切正文。允许更可读地分段不等于允许省略上下内容。

## 完整、版心和可读性发生冲突时

先用范本同页型的实际印刷尺度比较有效内容宽度、可见正文的物理字高和表格行高；电子文字可测字体，扫描页不伪造可测字号。没有用户约定的最低字号/容差时不自定通用数值，更不能仅放大预览证明成品可读。

如果清除重复边距、使用正确原件和优化授权标题区后，完整原件在固定版心内仍明显小于同型范本，记录实际尺寸与差异。保留完整内容和未改副本，不自行裁切、改纸张方向、折页或拆册；仅在既有授权范围内调整，确需改变版式范围时向用户提出具体取舍。原扫描本身模糊须注明来源限制，重采样放大不能声称恢复清晰度。该受影响页暂不放行，其他已验证页可继续。

## 缺页与重复的处理

分别判断：用户已删除、原稿本就缺、转换遗漏、两页叠到同页、重复插入。对照最新Word、PDF可见页、当前候选及下一标题，不从副本空白推断用户删除。

旧PDF没有的新Word通知/表格须保留；文字形式存在的原件尾条不应再以图片重复加入。相似名称或相同页数不足以认定两个材料相同。

## 可编辑文字与审校边界

若用户同时要求润色及留痕，确定文字问题做真实可接受/拒绝修订；待核业务事实、数据和正式名称用批注/高亮，不为顺句改事实。保留用户既有修订、批注和高亮；未经要求不强制全稿留痕或自动清稿。

## 单写入与有限并行

素材核对、参数提取、互不重叠补丁准备和已冻结页图的只读检查可并行；同一DOCX/PPTX、样式、媒体关系、目录和WPS窗口由唯一执行者写入。不同页段也不能同时写同一个包。子代理不同时控制桌面，不各自导出整本大文件。

同一范围返工交原执行者；只回传结果、实质差异、证据和未解项。缓存原件渲染时绑定源指纹、CropBox/旋转、分辨率和渲染器；改变这些条件即不可盲用旧缓存。

## 常见失败信号

标题整体错位通常先查材料映射/版本，不逐页猜标题；正文漂移先查分节、分页、浮动锚点与页脚，不拿旧目录硬配新页；图像失真先分清原件、预览和最终文件，不把宿主问题当成内容错误。
