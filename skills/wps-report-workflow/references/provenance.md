# 来源与验证边界

版本：1.0.0；封装日期：2026-09-07。

## 复用来源

- 本地 wps-local-sync：WPS 调用包装器、用户窗口保护、超时处置和已失败命令隔离。此次仅将固定用户名路径改成当前用户文档目录，并增加 WPS_CLI_PATH 显式入口；未替换旧 Skill。
- 本地 report-template-replication 1.0.1：四阶段操作参考、原文转录约束、原文及回执检查器与对应测试。正式名称遵循识别核实后直接复制，而非改写。
- 本项目实际校审：标题增删使用真实修订，接受/拒绝文字回读、原图字节保留、WPS双视图导出、逐页差异与局部断行复核。没有把业务文档、标题库、源截图或私有路径装入本包。
- vendor/wps-cli：复用本机实际使用的 wps-cli 0.2.0 本地兼容源码快照；保留 LICENSE（MIT）、pyproject.toml、README.md 和 src 下 Python 源码。原许可证及署名适用于第三方部分。排除虚拟环境、缓存、账号、日志和测试业务数据。

## 此次封装实际验证

- 原文转录检查器14项回归通过。
- 回执检查器24项回归通过。
- Skill 官方基础格式检查通过；WPS 包装器 PowerShell 语法检查无错误。
- 新包装器通过 WPS_CLI_PATH 连接原已部署隔离环境，只读打开现有294页 Word 并返回正确页数。
- 发包前逐文件指纹清单、压缩包解读和包内文件一致性验证；结果由包旁校验文件记录。

回归测试是合成输入的工具行为验证，不是38份真实报告验收。新路径适配器的只读调用通过，不代表已在另一台电脑全新部署或重新实测所有第三方命令。新电脑须安装依赖并以隔离小样验证实际 WPS 版本。

## 不作保证

不保证PDF转Word万能保真、自动OCR绝对准确、任意版本WPS全功能后台控制、多Agent必然提速或Token必然下降。完整业务制作仍需要用户原件、范本、范围及实际页面审核。

统一包是报告任务的组合入口；原 wps-local-sync 仍可服务其他 Office 格式，原 report-template-replication 仍可处理非WPS复刻。不要在同一个任务将三份入口全文重复加载；命中本包后，只在确有底层能力缺口时补充相关工具指导。
