# 阶段一：范本提炼与模板设计

目标：先解决“要保留什么、模仿什么、什么算排版合格”，再制作。输出保存在实际业务已有工作目录，不把完整历史复制进模板。

## 操作模式

1. 核验最新用户稿、原件PDF、样式范本、受保护封面及比较基线的真实身份。每类对象分别指定内容源、样式源、允许变化、冻结属性和验证方式。保留来源原文指针，旧指令被替代的范围明确。
2. 对实际页型逐类测量版式，建立参数表。已有模板须核对来源、宿主和版本适用性；新范本从样例反推，不用通用“公文格式”覆盖范本。
3. 复用可用的原生样式、模板或生成器，建立独立于内容的数据填充层。凡可编辑区域使用原生文字/段落/表格，不把样页截图作为整册模板。
4. 从内容权威稿建立材料清单，而非只抄目录；材料ID、原件页/对象、首末内容、下一标题/册尾、Word新增和用户删除分开。标题正式名称与目录简称是两个字段。正式名称必须按title-transcription.md从对应原件识别核实，不能把转换稿/旧外抬头作为已正确原文。
5. 选实际存在且最易失败的页型，在交付宿主渲染对照。全目录条目填满后验证分页；普通页成功不授权所有特殊页。失败先改对应模板，不进入全册批量。

三份输入同时出现时，不把两个PDF混称“旧PDF参考”：最新用户Word控制保留内容及用户手改；附件原件PDF提供对应材料的真实可见页；打印版/样式范本只控制用户指定的目录、抬头等外加版式。最新Word新增而旧原件没有的内容继续保留。这是对象分工示例，当前用户另有明确指定时按其指定。

## 版式参数表应记录什么

| 层次 | 必测对象与关系 |
| --- | --- |
| 页面 | 纸张尺寸、方向、分节、上下左右边距、页眉页脚距边、正文起码与封面/目录编号约定 |
| 文字 | 中文/西文字体实际字族、字号、粗细是否额外加粗、颜色、字符间距、字体替代情况 |
| 段落 | 行距类型与数值、段前段后、首行/悬挂/左右缩进、对齐、制表位、标题与下文同页、孤行控制 |
| 目录 | 各级字体/缩进、点引导线、页码右对齐位置、长条目续行、条目间距、跨页规则、整目录容量 |
| 图片/附件 | 图片对象框、实际可见页面、有效内容区三者；等比缩放、标题安全区、页码安全区、签章/末行完整性 |
| 表格/图例 | 行高、列宽、单元格内边距、边线、文字与框/符号距离、层级分组、逐行位置及相关图面 |

每项写清单位、范本页/对象、目标值、测量依据、实际值及不确定性。字体声明相同不等于宿主实际字形相同；原生16pt与导出实测值的差别须区分配置、渲染量化或替代，不能无依据改成另一个字号。

## 必测样页与小样放行

- 目录：预计全部条目、最长名称、跨页前后和末页，核对无空白占位、叠页、漏条目或页码挤出。
- 标题：最长两级标题的连续出现，检查自然断行、尾字落单、段距和与图像相接的位置。
- 原件：本次有的红头首页、普通续页、签章/抄送末页、满页表格、横竖混排及长截图断点。
- 图册：存在时检查长图例、多行伪表格、底图内嵌黑框、符号和文字叠加关系。
- 同尺度看完整页与必要局部；预览不显示实际底图或比例失真时，先修预览，不据此重排成品。

通过后冻结模板版本、来源指纹、样页和适用页型。模板变化只重开受影响页型，但全局目录规则变化须重新验证整个目录。

## 经验与反例

- **封面被参考稿替换**：局部样式源被扩大成整册权威。改用对象权威表；只有用户明确要求统一封面时才更换。
- **字面正确但看起来不对**：遗漏粗细、行距、断行和分组。文字不是单个字符串；用户明确授权重新设计时才可改变整体关系。
- **图片塞进版心后过小**：复合图片本身已有边距/抬头，再套一次版心。先识别来源类型；不能以“铺满”为由删除有意留白或裁掉原件。
- **横竖诊断反转**：嵌入图片或MediaBox可能含CropBox外内容，直接提取会带出PDF本来不可见的双页。以PDF阅读器实际可见页、CropBox和旋转为准；不要看到底层宽图就统一改横向或拆页。
- **小样成功而全册目录失败**：单页不能验证整个条目集合的容量和分页。先用完整目录数据测试，避免生成后反复改目录结构。
