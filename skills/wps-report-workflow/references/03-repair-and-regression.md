# 阶段三：局部修正与回归

目标：找出可验证原因，保持正确部分，避免“越改越回去”。

## 操作模式

1. 固定当前候选、对照原件、范本及最新纠正。记录缺陷页/对象、现象、要求和证据；先验证拿到的确实是目标版本，不信“final/v4”文件名。
2. 把问题分到下表，验证最小因果链再修改。历史原因没有复现则标待核，不把所有缺页都叫锚点问题。
3. 由原执行者处理失败集，保留修改前候选。若共用模板/来源规则失效，新建模板版本并回测对应小样后再应用，不在每页堆叠不同补丁。
4. 渲染实际修改结果，复查变化页、前后页、目录映射和保护对象。通过后冻结，剩余问题明确归属；同一无变化证据不反复召集审查。

| 问题类型 | 修正范围 | 必须回归 |
| --- | --- | --- |
| 字面/单个材料错误 | 对应文字或材料，事实不确定则待核 | 正式名称、目录简称及相邻边界 |
| 单页碰撞/留白异常 | 本页几何与段落，不擅改全局字号 | 本页完整原件、上下页、受影响分页 |
| 多页同型碰撞/缩小 | 共用模板参数和受影响页型 | 小样、该页型、全目录分页（若受影响） |
| 来源/标题批量偏移 | 源ID映射、插入/删除关系 | 全部受影响首末页和下一标题 |
| 预览/渲染失败 | 验证管线，先不重排原稿 | 真底图、比例、最终包和实际宿主 |

## 格式回归重点

- 字体改动可能改变断行和页数；检查实际字族/粗细、行距、标题与图像关系，不仅比文字内容。
- 只要求下移时冻结横坐标；只改颜色时冻结范围/位置；关联检查不自动扩成关联对象重做。
- 不用统一放大百分比、全册缩字或白色遮罩解决不同成因；排版共同错误应修模板，原件本身的斜拍/模糊不擅自美化。
- 目录修正后正文XML相同，只证明结构内容未变，不单独证明分页/视觉相同；必须查看实际导出。
- 差异缩略图可找疑似变化，不可证明小字、边线或像素位置不变。继承前版视觉证据须同来源/条件、全分辨率完整页精确像素相同，并绑定旧阅读证据。仅内容区相同不能免查标题、页脚和其他区域。
- 修复产生新缺陷时，不自动恢复整个旧版：确定受影响差异并保留其他通过项。系统性问题停用该方法，已有授权内继续局部验证和修复；仅需要新范围/权限/取舍时交还用户。

## 经验与边界

审查者曾把本轮中间稿当旧最终稿，产生错误归因。修复反馈至少带原件、旧基线、当前候选的身份和页/对象映射；主控先核身份，再决定是否采纳“旧稿也错”等结论。

曾出现目录页码自洽但源材料仍丢失：一致性不是完整性。也出现旧修复稿的横向处理被后续PDF可见页证据否定：曾通过的结论可以被更强证据撤回，不能为维护旧“成功经验”继续沿用错误规则。
