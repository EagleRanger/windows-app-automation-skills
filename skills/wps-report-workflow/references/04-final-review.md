# 阶段四：全册审核与交付

目标：用实际当前文件证明内容完整、排版符合范本且能交付，区分内部验证和用户接受。只要求检查单页或只读诊断时限定结论，不借审核改文件。

## 审核顺序

排版审核先按随包的 [分类排版与检查规范](layout-quality.md) 确定角色、实际格式、检查等级及本轮覆盖范围。规则来自 `report-template-replication` 经校验快照；下表用于阅读验收，不能用内容比对、页数或包检查的成功替代。

1. **身份与证据**：核对原件、样式范本、旧基线、当前候选、最终路径及指纹。导出快照绑定输入，文件变更使旧快照失效；先证明所看版本正确。
2. **结构与内容**：ZIP/包及媒体关系、真实可编辑对象、源材料首末/下一边界、原件顺序及唯一覆盖、所有目录定位/正文页码、保护内容和已授权删改。目录自洽不证明材料齐全。
   正式抬头另按title-transcription.md逐字读回对照原件已核实文字；编号、锚点、项目相似或与旧稿相同都不算名称通过。仅空白/换行可忽略，文字与标点差异不得自动放行。
3. **渲染可信度**：实际底图、比例、方向、字体可见；空白TIFF或失真预览不能判成品。必要时做可追溯QA副本，最终包与宿主呈现另验。
4. **正常阅读尺寸逐页排版**：完整交付覆盖全部物理页，按下表检查。缩略总览只发现问题；密集表格、签章、长标题、断点及细边线局部放大并查相邻页。
5. **独立审查与修复**：重要复杂成品由用户与宿主允许的独立审查者读取真实原件/范本/候选，不固定或自动升级到特定模型，不能只读回执。原执行者修复，复查变化及关联范围；主控自己再看不是独立审查。
6. **正式路径读回**：保存/另存到交付位置后实际重开、导出；核对正式文件与验收候选一致。WPS被占用不抢窗口或强关；文件存在、导出成功和用户看到正确内容是不同证据。

## 逐页排版检查表

| 重点 | 应验证的可见结果 |
| --- | --- |
| 页面与边距 | 纸张/方向、版心和有效内容尺度匹配范本；没有重复边距、异常缩小、故意留白被删或页脚撑页 |
| 字体与段落 | 中文/西文字族、字号、实际粗细、颜色、行距、段距、缩进一致；无替代字体、局部多加粗或段落挤压 |
| 标题与阅读顺序 | 层级明确，长标题自然断行，无两级叠字、孤立标题、尾字落到图下；标题确属后续原件 |
| 目录 | 全条目与实际位置相符，点线/缩进/页码列整齐，续行自然，跨页不丢条目、不叠页；编号规则符合本次要求 |
| 扫描/电子原件 | 比例/可见范围正确，红头、章、表格末行、边框和尾条完整；无额外印章、网页标志或OCR复本 |
| 图文关系 | 外加标题/原件/页码不遮挡；表格字在对应行内，数字和正文列不串位；图例/色块/符号/图面一致 |
| 人的阅读体验 | 正常大小可读，密集页不靠统一缩小糊成一团，疏密有依据，页间层级连贯；忠实原件与美化授权分开 |

按模板参数记录实测值和残差。零遮挡/漏页等内容约束不因微小坐标容差放宽。一比一要求不能由“观感接近”代替；宿主量化或原件模糊造成不能完全一致时，说明具体范围，不能自定容差宣称完全复刻。

## 覆盖与结论

- 每页记录本次实际阅读，或同条件全分辨率完整页像素相同与原阅读证据的合规继承；部分区域未变只继承该区域，其他部分仍需核验。
- 结构通过、内容完整、视觉合格、宿主重开及用户接受分开报告；检查器退出0最多说明回执一致。人工填写pass不证明看过页面。
- 尚有错源、漏页、遮挡、变形、标题错位、目录错误或不新鲜证据，不称无问题终稿。可交付明确列明问题的审阅候选；剩余范围可继续修复时持续推进。
- “零新增错误”不等于原文件无错，“两稿均完成”不等于质量相同。用户接受只依据对应版本与范围的明确反馈。

## 运行对比

比较时冻结输入、最新要求、复用素材/模板、模型实际档位、工具、页型与验收范围。大范围修复旧稿和从源重做分列；首次提炼模板与重复填充分列。记录首次缺陷、返工页/轮次、用户漏检、完整墙钟、分段和可得用量，不把统计截点当结束、不把缓存输入再加一遍、不将token当账单。没有受控比较，不归因“模型更强”或“更多Agent更快”。
