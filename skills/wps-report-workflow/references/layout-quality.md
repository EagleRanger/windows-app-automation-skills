# 公文、报告与附件册：分类排版与检查规范

适用于模板定型、实际排版及最终格式审核。此文件固定执行判断和验收契约，不是自动排版器，也不代表下列检测均已编程实现。具体材料、参数、指纹和测试结果留在业务项目。

## 1. 先确定规则适用对象

| 对象类型 | 格式依据 | 不能误套的要求 |
| --- | --- | --- |
| 公文 | 本次适用的正式标准、机关补充要求及用户指定范本；执行具体标准前核对有效版本和原文条款 | 不把个人 Skill 的固定行距、字体商品名说成国标；不把公文主标题的有意分行套到目录 |
| 工程报告 | 当前业主或单位模板、适用专业要求；未授权部分沿用原稿 | 不全册套红头公文，不统一改表格形式或编号 |
| 附件汇编 | 最新用户稿控制保留范围，指定范本控制外部版式，原 PDF 控制原件内容 | 不重排图像内部文字，不抄 OCR 行边界，不重复叠加图片内外边距 |

混合文件逐对象分配规则。用户最新明确选择优先；与适用标准有冲突则说明，不能静默覆盖用户选择，也不能虚称符合标准。仅改目录时，不因此修改封面、正文、扫描材料或正文页码。

## 2. 模板定型：可测量的角色约定

按实际需要区分主标题、各级标题、正文、目录层级、附件抬头、图表题注、扫描原件和页脚。每类记录适用范围、来源、字体/字号/粗细、段距/行距、缩进、有效宽度、相邻和分页关系。小改动只记录相关角色。

- 比较同角色，不能用全篇字体数或行距种数作为合格阈值。
- 读取实际生效格式：文档默认、继承样式、段落和字符直接格式；分别核对中文与西文字体、主题引用及实际可用字体。只读取 run.font 或样式名不足以判定。无法解析的值标未知，再核实宿主显示；不得当作零值或默认通过。
- 版心以纸张、分节、边距及容器共同决定；段落宽度还受左右缩进、表格单元格、文本框或框架限制。检查真实可用宽度，不只比较页边距。
- 黑体不等于必须额外加粗。缺字库、字体替代、字号挤压必须定位；不得为凑页数静默替代或统一缩小。
- 范本中无法精确测量的数值明确未知；不能自定容差宣称一比一复刻。

## 3. 制作与静态检查

### 目录自然流

一个条目一个段落；条目之间的正常段落分隔保留。自然流目录禁止把 OCR/旧 PDF 的行边界作为手动换行复制。仅实际超过一行时自动折行，不按固定字数截断。

检查条目内换行、额外右缩进、限制宽度的框架、空格凑齐、手打点号和异常制表位。页码采用约定的右对齐制表位及引导线，保持与对应条目的阅读联系。既有明确固定版式对象先分类，不能全文件无差别删除换行或框架。

长标题的自然短尾行不是自动错误。先核对有效宽度、标点禁则和页码；正常则保留。不为配平末行缩窄文字区、插入硬换行、缩字、删字或改标题。

### 分页与相邻关系

检查 keepNext、keepLines、pageBreakBefore、空段及浮动锚点的作用范围。标题通常与后文相邻；短目录条目可按约定保持完整。不能一律取消分页约束，也不能把长正文或长表整块锁住，导致被推到下一页。章节或附件另页须有来源依据。

### 内容与扫描件保护

格式操作不得补写、概括、改标点或重新生成正式题名。目录与标题须对照独立的已核实来源，不能只与同一生成流程产出的清单互相印证。扫描图等比、内容完整，保留原件内部留白；避免外部多加边距造成异常缩小。允许拆长图时按已授权规则核对连续覆盖，不擅自裁切。

用户要求修订时保留真实修订；仅打开“修订”开关不证明所有改动已记录。按本次变更类型核对文本、段落及其他格式变更的记录和可还原性，不能自动接受原有修订。

## 4. 渲染后的页面检查

在交付宿主实际渲染，以正常阅读尺寸从上到下读，再对照范本和相邻页。缩略图、XML 参数和截图已生成都不能代替视觉检查。

| 检查项 | 默认处理 |
| --- | --- |
| 遮挡、裁字、丢图、内容越出可见范围、变形 | 确认后为硬错误，修复并复验 |
| 目录非末行明显提前结束、页码单独掉行、引导线碰撞 | 定位条目和宽度/制表位/断行原因；确认违反约定后为硬错误 |
| 孤立标题、图与说明分离、无依据的大空白 | 提示复核相邻关系、分页及对象类别，不能直接删除空白 |
| 自然短尾行、原扫描件留白、章节有意另页 | 先复核，符合约定可保留；不得自动“美化” |
| 图片虽完整但异常小、正常尺寸难辨认 | 比较范本有效尺度与原件质量，区分缩放失误和源图分辨率限制 |

自动几何检测只能提供可定位线索，需按角色校准阈值。扫描页不能因提取不到文字就判空白页。视觉结果与静态结果不一致时定位实际原因，不用静态 PASS 推翻可见问题。

每个发现至少关联：文件版本/指纹、物理页及条目、规则依据、期望与实际、证据位置、严重程度、处理结果。正常空白无需重复建大量记录；保留有争议或影响验收的判断依据即可。

## 5. 验收分层与效率

分开报告：内容核对、保护区回归、实际格式、视觉阅读、修订/还原、宿主重开。检查项使用“通过、失败、待复核、未检查、不适用”，不适用要说明理由。没有执行的检测不填通过；缺少必要检查不能称已完成全项验收。

检查结果绑定源稿和候选指纹、渲染宿主/版本、实际检查范围与证据。旧稿像素一致只证明未变；继承视觉通过须有同条件完整区域和旧阅读证据。原基线有错不能凭一致性放行。

先做覆盖最长/最短目录、层级、长页码、跨页标题和特殊图表的隔离小样；每次局部修改复查受影响页及关联分页，不反复全册导出试参数。共用样式变化扩大回归范围。定型后实际宿主全册分页、内容核对与阅读验收不能省略；可按已有证据合法继承未变页。若宿主不支持可靠的局部预览，说明限制，不用不同渲染器的小样冒充宿主验收。

## 6. 检查器的真实回归样例契约

新建或修改检测器时，在隔离 DOCX 小样中实际注入下列错误，并配置对应正确对照，验证检出与误报；不能只测试文案或关键词是否存在。

| 反例 | 正确对照 | 应有结果 |
| --- | --- | --- |
| 自然流目录条目被插入硬换行 | 相同标题仅自然折行 | 前者检出，后者不因短尾行误报为失败 |
| 目录额外右缩进导致提前折行 | 约定版心内正常宽度 | 定位宽度差异，不通过缩字修复 |
| 长正文整段锁定形成无依据空白 | 标题与后文合理绑定、附件有意另页 | 检出错误约束范围，保留合法分页 |
| 样式名正确但中文字体被直接格式覆盖 | 多级标题采用不同但约定正确的字族/字号 | 检出实际格式差异，不按字体总数误报 |
| 外部重复边距导致扫描件异常缩小 | 原扫描件自身存在白边 | 区分放置错误与原件特征 |
| 标题覆盖图像或页码掉行 | 同页清晰相邻且不重叠 | 实际渲染可定位异常；文字比对相同不算通过 |

静态、渲染和修订还原测试分别执行，记录成功、失败及未实现项。上述为待执行测试契约，不是已通过用例；没有真实回归结果，不宣称精准度或速度已提升。外部检测器先只读验证，不在正式报告上直接运行自动清理。

## 来源与边界

这些规则根据用户已确认的报告复刻要求独立整理；借鉴外部方法，不复制第三方代码或模板，不作第三方成熟度背书。

- [公文排版检查器](https://github.com/Yihang-Wang/official-document-standards-and-formatting-skill/blob/main/artifact-template-official-document-standards-and-formatting/scripts/verify_official_document.py)：借鉴分页约束、渲染留白及人工复核的组合；不继承其固定版面参数或针对纯文字页的空白判据。
- [format-agent](https://github.com/KaguraNanaga/format-agent-skill/blob/main/SKILL.md)：借鉴格式依据、角色及完整性分离；不采用可选视觉验收或不完整修订覆盖作为本流程默认。
- [格式分析程序](https://github.com/KaguraNanaga/document-format-skills/blob/main/scripts/analyzer.py)：借鉴分类定位，不采用全篇字体数量/行距差异直接判错，也不把直接格式读取当作实际格式解析。

公文具体标准参数须另核对适用权威原文；此规范不内置未经逐条核实的“国标参数表”。
