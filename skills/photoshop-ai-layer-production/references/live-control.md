# 实时控制与保存边界

## 已验证的 Windows 路线

1. 用户正常打开 Photoshop，处理所有模态对话框，并打开目标文件。
2. 确认可见且响应正常的 Photoshop 主窗口。
3. 通过 Windows Running Object Table 附着现有 `Photoshop.Application`，再用 `DoJavaScript` 执行有界 ExtendScript。
4. 第一次写入前，在 Photoshop 内读取并核对：版本、进程/窗口、文档数、活动文档完整路径、尺寸、DPI、色彩模式、保存状态和预期源文件身份。
5. 只在命名清楚的独立图层或组中操作；同一实例、活动文档和保存流程串行。

进程存在、MCP 握手或会话可读均不等于能够写入。不要让桥接器用 Automation/Embedding 参数静默启动一个不可见实例。

## 写入准入

- 活动文档不是精确目标、完整路径不可读、存在不明未保存文档、模态窗口未排除或实例含糊时，停在写入前。
- 新控制路线先在隔离文件做最小可逆写入；生产文件只复用已验证路线。
- 默认保留所有原图层与像素，不合并、不扁平化、不覆盖、不关闭。
- 保存是独立授权边界。优先另存新 PSD/PSB；输出已存在时默认拒绝覆盖。

## Photoshop 2021 兼容约束

- ExtendScript 可能没有全局 `JSON`；嵌入已验证的对象字面量，或随脚本提供兼容解析器。
- `LargeDocumentFormatSaveOptions` 在部分版本不可构造；PSB 使用 `ActionDescriptor` 和 `largeDocumentFormat` 保存。
- 隐藏父组在保存时若为活动层，重开后可见性可能反弹。先激活稳定的可见校准层，再隐藏父组并保存。
- `TextItem.horizontalScale` 可能以整数持久化。先量化横向缩放，再用 tracking 补偿余下行宽误差。

## 中断核对

长时间复制、导入、保存或重开超时后，不立即重放命令。只读检查一次：窗口标题、活动文档、文档数、命名临时文档、目标文件存在性、图层名和保存状态。

只有当自动化创建的精确命名临时文档是唯一未完成对象，且原保存文档仍可确认时，才可关闭该临时文档且不保存。不得以强制结束 Photoshop 代替核对。

## 证据词汇

- `connected`：附着到目标可见实例。
- `readable`：读取到当前文档状态。
- `written`：观察到目标图层、对象或像素变化。
- `saved`：授权路径存在且 Photoshop 报告已保存。
- `reopened`：关闭并重新打开后结构仍成立。
- `visually_accepted`：渲染对比或用户检查通过；它不由结构检查自动推出。
