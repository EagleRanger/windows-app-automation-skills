# 验证范围与非承诺

## 原本地功能基线（2026-10-06）

- Windows、ArcGIS Pro 3.4.3 build 55405、ArcInfo、Python 3.11.10。
- 34 个前台 SDK 接口：32 个接口在 v1.1.3 的 47 次调用中验证；v1.1.4 补充两个栅格配色接口并复用相关控制接口验证。TCP 和 HTTP MCP 有真实返回。
- 前台 GP 仅 Buffer、Clip，禁用未列入白名单的处理和任意 Python 回退。
- 后台另有 36 个安装内置工具实测通过，不与前台 34 接口相加作“70 种分析工具”。安装清单的 1936 个工具/46 个 toolbox 没有全量实测。

插件命令和 JSON 参数的权威是 `assets/addin-source/Resources/tools.json`。原插件保留 `check_extension` 接口，但本 Skill 默认客户端拒绝该许可入口；其余接口也受只读/显式写入约束。不要把“34 个接口”理解为客户端默认全部可执行。

完整对应源码中的 `local_profile.json` 保留构建基线原件，其中端口和 `style_status` 是早期历史快照，不是接收方配置或本包验收。实际连接从新鲜实例发现，不复制快照端口。

## 当前公开包（v0.1.1）

对应源码、许可证、构建、客户端模拟测试、敏感内容扫描及 ZIP/远端回下载一致性，分别记录在发布回执与 RELEASE_NOTES 中。沿用 v0.1.0 无符号公开构建的插件，未改变业务代码；本版仅收窄包内容为自动化控制，移除配色方案附件。26 项离线测试通过。

本次没有启动或操作真实 Pro，没有加载新 AddIn，没有调用真实 ArcPy，没有修改已安装软件，也没有将用户地图、工程或数据上传。新包在接收方环境中的安装、连接、导出、保存和读图仍需验收。其他 Pro 版本、不同许可与 macOS 不在通过范围。

先前“runtime_now=false”的后台候选是旧阶段记录，不能覆盖更新后的原功能基线；旧阶段失败与后续修复要分开。公开包不会夹带这些过时的本机状态文件。
