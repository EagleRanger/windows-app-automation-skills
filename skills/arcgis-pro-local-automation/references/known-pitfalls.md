# 我们已踩过的坑

- **版本不能只改 manifest**：Pro SDK 程序集和 .NET 目标必须真实匹配。本版固定 Pro 3.4/.NET 8；其他版本不承诺可直接用。
- **早期连接失败不是当前状态**：原生组件异常阶段已恢复，后续完成真实调用。本包不提供替换 Esri DLL 等环境修补。
- **旧实例记录会残留**：不能只信 JSON 中的 PID/工程，必须 fresh ping 和工程身份核对。
- **上游 activate_map 曾超时**：本地派生版改为异步控制后通过；不能把上游原版的失败或派生版的成功混为同一版本结论。
- **激活地图可能先返回空 camera**：新 pane 尚未就绪时先做有界只读检查，不把激活返回当成视图已可操作。
- **另存会切换当前工程**：SaveAs 后重新读工程路径；不要沿用原工程身份继续写，也不要重复另存。
- **工具清单不是可用证明**：前台 GP 仅 Buffer/Clip；后台遇到安装中不存在的入口要在调用前停止。原生崩溃无新差异不原样重试。
- **原包 PDB/DLL 带本机路径**：公开包已无符号重编译；新二进制尚未实机加载，不能冒用原包验收。

仅记录已知经验，不是通用排障指南。接收方的新环境和新 bug 由接收方自行定位处理。
